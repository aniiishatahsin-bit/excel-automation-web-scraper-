# excel-automation-web-scraper-
# 🚀 Automated B2B Lead Generation & Excel Styling Engine

A professional Python-based data automation script that eliminates manual data entry. This project extracts/generates B2B business leads and uses an automated styling engine to deliver client-ready, beautifully formatted Excel spreadsheets in seconds.

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Data Manipulation:** Pandas
- **Excel Formatting:** Openpyxl

## ✨ Key Features Implemented via Code
- **Corporate Visual Theme:** Programmatically applies a polished **Deep Navy Blue** theme (`#1B365D`) to headers with white bold text.
- **Zebra Striping:** Automatically shades alternate rows with a light grey/blue tint to maximize data readability.
- **Dynamic Conditional Formatting:** Auto-highlights business leads based on status (e.g., Active leads in **light green**, Pending leads in **light yellow**).
- **Native Formula Injections:** Injects Excel's native `=COUNTA()` formula directly through the Python script to display automated total metrics.
- **Auto-Fit Columns:** Dynamic column width calculation to prevent any text clipping or overlapping.
